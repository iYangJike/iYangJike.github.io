# GitLab 订阅链接 + GCP 白嫖机搭 HY2/TUIC 步骤总结

承接「GCP Always Free 小机」教程：用甬哥 Sing-box 一键脚本搭出 HY2/TUIC 后，借助 GitLab 生成真正的 **https 订阅链接**，方便客户端订阅更新。政策与界面可能变化，以官方文档与当前控制台为准。

## 本期在补什么

上一期脚本生成的多半是**单节点链接（或「四合一」只是把几条链接拼在一起），不是真正的订阅 URL**，很多客户端无法直接用。

本期目标：在 GitLab 建项目 + Access Token，在脚本里生成：

- Sing-box 订阅
- Clash-Meta 订阅
- 通用订阅链接

## 为什么仍用一键脚本，不用 X-UI

1. GCP 免费机是**标准网络层级**，普通节点偏慢，更适合 **UDP 协议**（HY2、TUIC）
2. 图形面板里能做这类节点的主要是 S-UI / H-UI，偏复杂、不够稳；**X-UI 不支持**这类 UDP 节点
3. 一键脚本参数默认好，少配置，更适合小白

## 一、Google 账号：两步验证

自约 5 月 13 日起，GCP 可能要求开启两步验证，否则可能无法正常使用控制台。

1. 按提示进入安全设置
2. 可用：手机号（支持 +86）、Google 提示、Authenticator 动态码等，**至少一种**
3. 设好后刷新，相关提示应消失

## 二、补防火墙（上期易漏，常导致节点不通）

云厂商默认常**屏蔽入站**。

1. 实例 → 三个点 → **查看网络详情** → **防火墙**（或顶栏搜「防火墙」）
2. **创建防火墙规则**：
   - 名称任意
   - 流量方向：**入站**
   - 目标：**网络中的所有实例**
   - 来源 IPv4：`0.0.0.0/0`
   - 协议和端口：**全部允许**
3. 默认主要挡入站，**出站规则可不建**
4. 脚本里「关闭防火墙」只关**系统内防火墙**，**不能替代** GCP 控制台这条入站规则

## 三、甬哥脚本安装节点（可重装演示）

1. 打开 [cloud.google.com](https://cloud.google.com) → **控制台** → Compute Engine → **虚拟机实例**（首次启用 Compute Engine API）
2. 网页点 **SSH**（小白推荐；第三方 SSH 可看往期）
3. 执行：`sudo -i`（切 root）
4. 打开甬哥 GitHub → 复制 **VPS 专用一键脚本**（选第一个）→ 粘贴回车
5. 首次装依赖：保存 IPv4 / IPv6 规则时输入 `y`（通常只第一次出现）
6. 选 `1` **一键安装** → 其余多半一路回车
7. 证书：图省事用**自签**；有域名更建议**域名证书**（解析到 VPS IP 后申请）
8. 端口随机即可 → 生成单节点链接（含 HY2 / TUIC 等）

此时还是**节点链接**，不是订阅。

## 四、生成 GitLab 订阅链接（核心）

### 4.1 在脚本菜单里

1. 退出后重新进入：快捷命令 `sb`
2. 选 `3` **（订阅相关）** → `7` **设置 GitLab 订阅分享链接** → `1`
3. 按提示准备：GitLab 上已有项目、可强制推送、已拿到访问令牌

### 4.2 在 GitLab 上准备

1. 打开 GitLab → 注册/登录
2. **新建空白项目**：
   - 命名随意
   - **命名空间选个人用户**，不要选群组
3. **设置 → 仓库 → 受保护分支**：展开后开启 **允许强制推送**
4. **项目访问令牌**：
   - 名称随意
   - 到期尽量拉最长（最长约一年）
   - 角色：**Owner**
   - 范围勾选：**API**
   - 创建后**立刻复制保存**（只显示一次）

### 4.3 回到 SSH 填信息

按脚本询问填写：

- GitLab **登录邮箱**（Google 登录则用 Gmail）
- **访问令牌**
- **用户名**（地址栏 `gitlab.com/` 后面那段）
- **项目名**
- 是否新建分支：直接回车（不新建）

成功后得到 **https 开头的订阅链接**（Sing-box、Clash-Meta、通用等）。

### 4.4 客户端使用

例：v2rayN → 新建分组 → 粘贴订阅地址 → **更新当前订阅** → 出现节点列表。

GitLab 项目里会看到刚推送的订阅文件。

## 五、HY2 vs TUIC（使用建议）

| | Hysteria 2 | TUIC |
| --- | --- | --- |
| 协议 | UDP，「暴力」抢带宽，提速明显 | 也是 UDP，但更温和 |
| 风险 | 短时大 UDP 可能触发运营商 QoS，出现断流 | 相对不易触发限制，丢包环境更稳 |
| 断流时 | 可先切别的节点，过几分钟再试 | — |
| 建议 | 可测 | **更推荐日常优先用 TUIC** |

## 六、流程一览

```
GCP 免费机就绪
  → 开启两步验证（如被要求）
  → 创建入站防火墙放行
  → sudo -i + 甬哥 VPS 脚本装 Sing-box（HY2/TUIC）
  → sb → 3 → 7 → 配 GitLab 邮箱/Token/用户名/项目
  → 得到 https 订阅链接 → 客户端订阅更新
```
