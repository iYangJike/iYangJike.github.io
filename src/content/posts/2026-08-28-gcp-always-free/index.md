# 永久白嫖谷歌云（GCP）Always Free 小机 + Hysteria 2 步骤总结

根据公开教程整理的操作摘要。GCP Always Free 与计费规则可能变更，动手前请对照[官方 Always Free 文档](https://cloud.google.com/free/docs/free-cloud-features)与账单。本文不是谷歌官方「永久零费用」承诺。

## 一、免费条件（必须同时满足）

### 机器（Always Free 计算）

- 地区仅限：`us-west1`（俄勒冈）/ `us-central1`（爱荷华）/ `us-east1`（南卡）
- 机型：`e2-micro`（非抢占）
- 磁盘：`标准永久性磁盘`，**正好 30GB**（不能多也不能少）
- 账号内这类免费机：**只能 1 台**

### 流量

- 网络服务层级选 **标准（Standard）**
- 每月约 **200GB 出站**免费（标准层级）；入站一般更宽松
- **不要**走 Cloudflare CDN / Argo 等（出站到 CF 可能不走免费标准层级，可能计费）
- 官方文档另有约 1GB 等条款；实际以 GCP 账单与官方 Always Free 为准

## 二、注册 Google Cloud

1. 打开 [cloud.google.com](https://cloud.google.com)，用**没用过 GCP 试用**的 Google 账号登录
2. 「免费开始使用」→ 选国家（建议美国）→ 同意
3. 添加付款资料：个人；地址可用生成器，教程建议俄勒冈（免税州，且后面机器也选俄勒冈）
4. 绑一张能扣美元的 Visa/Master（外币信用卡；虚拟卡成败不一）
5. 进入控制台后会看到 **$300 / 90 天试用**
6. **先不要点「激活完整账号」**（试用期内超支通常停服不扣卡；期满再按需激活）

## 三、创建免费 VM

1. **Compute Engine → 虚拟机实例 → 创建实例**
2. **区域**：建议 **俄勒冈（us-west1）**（相对离中国近）
3. **系列 E2 → 机器类型 e2-micro**
4. **启动磁盘 → 修改**：
   - 系统：Linux（常用 Ubuntu 22.04 x86_64；勿选 Windows）
   - 磁盘类型：**标准永久性磁盘**
   - 大小：**30 GB**
5. **网络**：勾选允许 HTTP / HTTPS
6. **网络接口 → 网络服务层级：改为「标准」**（关键，关系到免费流量逻辑）
7. 创建 → 核对：地区、e2-micro、30GB 标准盘、Standard 层级
8. 记下外网 IP（临时 IP：不关机一般可长期沿用同一 IP）

## 四、防火墙（方便起见可全放行）

1. 实例 → 更多 → 查看网络详情 → 防火墙
2. **入站规则**：目标=网络中所有实例；源 `0.0.0.0/0`；协议端口=全部允许
3. **出站规则**：同理，方向选出站，`0.0.0.0/0`，全部允许

生产环境应只开需要的端口；教程面向小白图省事才建议全放行。

## 五、SSH 登录

### 方式 A（最简单）

实例页点 **SSH** → 授权即可（网页终端）。

### 方式 B（第三方客户端，如 WindTerm）

1. 本机 `ssh-keygen` 生成密钥对（可无密码）
2. 打开 `.pub` 公钥，复制全文
3. GCP：**元数据 → SSH 密钥 → 添加** → 粘贴 → 保存
4. 客户端用：**IP + 密钥里的用户名 + 私钥文件** 连接

## 六、搭 Hysteria 2（教程推荐「甬哥」VPS 一键脚本）

背景：线路是美国 + 标准层级，普通代理可能慢；实测 **Hysteria 2** 更可用。面板里 X-UI/3X-UI 不方便上 HY2；教程不推荐复杂 H-UI/S-UI，改用一键脚本。

1. SSH 登录后执行：`sudo -i`（切 root）
2. 粘贴并运行甬哥项目里的 **VPS 专用脚本**（与 Serv00 那套同一作者，选 VPS 脚本）
3. 首次会装依赖；提示保存规则时输入 `y`
4. 选 **1 安装 Sing-box**
5. 开放端口/关防火墙、内核等：**一路回车按默认**
6. 证书：无域名可用**自签**（可跳过证书校验；有域名可后续再配置）
7. 端口：回车随机即可
8. 复制生成的 **Hysteria 2** 节点链接 → 客户端（如 v2rayN）导入 → 测连通 → 设为活动

## 七、90 天试用结束后

1. 试用到期服务可能停；需回控制台 **激活完整账号** 才能继续
2. 激活后 GCP **有权扣费**，但只要：
   - 配置仍严格符合 Always Free（e2-micro + 三区之一 + 30GB 标准盘 + 标准网络层级）
   - **不超免费流量**
   - **不用 Cloudflare CDN / Argo 等易计费用法**
   
   按教程说法可继续使用这台免费规格机

3. 旧账号若试用已用过，也可激活完整账号后**只建这台免费规格机**（以当前 GCP 政策为准）

## 八、必记避坑

| 项 | 要求 |
| --- | --- |
| 机型/地区/磁盘 | e2-micro + 三区之一 + 标准盘 30GB |
| 网络层级 | **标准**，勿默认高级 |
| 流量 | 盯约 200GB；代理主要吃出站额度 |
| CDN | **别**挂 Cloudflare / Argo |
| 试用期 | 未激活完整账号前相对安全；到期再激活并严控配置 |
| 加速 | 标准线路优先考虑 **Hysteria 2** |

## 九、一句话复查清单

创建实例后自查：

1. 区域是否为 us-west1 / us-central1 / us-east1
2. 是否为 e2-micro
3. 是否为标准永久性磁盘且正好 30GB
4. 网络服务层级是否为「标准」
5. 防火墙是否已按需要放行
6. 是否避免 Cloudflare CDN / Argo
